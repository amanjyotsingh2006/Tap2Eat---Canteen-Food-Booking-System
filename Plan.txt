## One recommendation that will save you time

Before writing any code, spend **2–3 hours designing the database and API contracts**.

For example:

* List every collection (`User`, `FoodItem`, `Order`, etc.).
* Decide what fields each collection has.
* Write every API endpoint (`POST /auth/login`, `GET /foods`, `POST /orders`, ...).
* Decide which role (user/admin) can access each endpoint.

That planning step prevents a lot of refactoring later and makes the 10-day schedule much more achievable.
